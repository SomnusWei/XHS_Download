# XHS_Download（小红书作品批量采集下载器）

个人使用的 Windows 桌面工具：左侧为**内嵌浏览器**，可直接浏览小红书；输入**小红书号**或**作者主页链接**抓取该作者主页作品列表（区分图文/视频），勾选后**加入后台下载队列**，把原图/视频下载到本地。**下载全程不占用浏览器**，可边下载边继续浏览、抓取、追加任务。

## 功能

- **内嵌浏览器**（左侧实时页面，右侧操作与数据）：登录/滑块验证码直接在窗口内处理，登录态自动持久化（重启免登录）

- **三种抓取方式**：输入纯数字小红书号 / 粘贴作者主页链接 / 留空抓取当前内嵌页面的作者；抓取失败/当前页不是主页时给出可操作引导

- **作品列表**：类型徽标（图文/视频）、封面缩略图、标题、点赞数、勾选、统计；支持 **全选 / 全选图文 / 全选视频** 三组联动（含半选态）

- **抓取记录**：每次成功抓取自动记录「用户名 | 小红书号 | 主页链接」，本地持久化（重启保留、同作者去重置顶、上限 300 条）；工具条「查看记录」弹窗查看/清空

- **后台下载队列**：点「下载勾选」把作品**加入任务队列**（非阻塞），下载期间左侧浏览器可继续浏览/抓取/勾选/追加任务；右下角任务面板实时显示 **等待 / 进行中 / 完成 / 失败**，支持 **暂停 / 继续 / 重下失败**

- **断点续传**：任务队列本地持久化（`tasks.json`），重启后自动恢复未完成任务并继续；已完成文件按文件粒度自动跳过、半截文件清理后重下

- **单实例**：程序已在运行时，再次双击 exe/启动源码只会**唤醒已有窗口**，不会重复打开

- **下载**：原图（图文全部图片）与视频文件，任务级并发 + 文件级限速、单文件失败重试；落盘结构 `目标目录/作者昵称/标题_笔记ID/`（图片 `01.jpg…`、视频 `视频.mp4`）；二次运行自动跳过已下载；下载目录本地持久化，可一键打开

## 运行方式

### 打包版（推荐）

从 [Releases](../../releases) 下载最新 `XHSCollector-vX.Y.Z.zip`，解压后双击 `XHSCollector.exe` 即可（无需 Python 环境）。

> 首次运行需在窗口内扫码登录一次；登录态、配置、抓取记录与任务队列保存在系统用户目录 `%LOCALAPPDATA%\XHSCollector\`，不会因覆盖/重打包丢失。

### 源码运行

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
.\.venv\Scripts\python.exe main.py
```

## 使用说明

1. 启动后左侧为内嵌浏览器（自动打开小红书主页），右侧可按需直接浏览/打开作者主页
2. 在右侧输入框：

   - 输入纯数字**小红书号** → 点「抓取」（自动站内搜索解析，未命中会重试并直开主页兜底）
   - 或粘贴 `/user/profile/` 开头的**主页链接** → 点「抓取」
   - 或**留空** → 点「抓取」收集左侧当前作者主页作品
3. 列表出现后，用「全选 / 全选图文 / 全选视频」或逐行勾选作品 → 「浏览…」选目标目录 → 点「下载勾选」加入队列
4. 队列处理中可**继续在左侧浏览、抓取其他作者并继续添加任务**；右下任务面板与状态列实时显示：已排队 → 获取详情/下载中 → 完成 / 已存在(跳过) / 失败
5. 中途可「暂停」队列；会话过期会**自动暂停**并提示，重新登录后点「继续」；失败任务可「重下失败」
6. 点「查看记录」回顾抓取过的作者；点「打开目录」查看下载结果
7. 正常退出/重启程序后，未完成的任务会自动恢复续传（断点）

## 技术要点

- **浏览器自动化**：DrissionPage + QtWebEngine（内嵌），页面自签名，无需自行实现 x-s 逆向

- **列表采集**：监听 `user_posted` 响应 + 自动滚动分页；小作者主页由 SSR 直接渲染时自动解析 `__INITIAL_STATE__` 兜底

- **详情采集（不占浏览器）**：默认走 curl_cffi 携带浏览器 Cookie 快照**直取笔记页 HTML**，解析 SSR `__INITIAL_STATE__`（PyYAML）提取原图/视频流地址——详情与下载都在后台 HTTP 通道完成，因此下载期间左侧浏览器可继续使用

- **媒体下载**：curl_cffi 模拟浏览器指纹直连 CDN（免 Cookie），无需 x-s

- **任务队列**：后台线程池（默认 2 路）消费 `TaskItem`；`tasks.json` 本地持久化实现重启续传；文件级跳过复用确定性目录 + `has_existing`

- **单实例**：`QLocalServer` 唤醒置顶 + `QLockFile` 防崩溃残留（开发版与打包版互斥，避免 CDP 端口冲突）

- **GUI**：PySide6 + QtWebEngine；打包：PyInstaller

## 数据与本地文件

| 文件（位于数据目录） | 说明 |
| --- | --- |
| `history.json` | 抓取记录（用户名/小红书号/主页链接），上限 300 条 |
| `tasks.json` | 下载任务队列（断点续传恢复依据） |
| `settings.json` | 下载目录等本地配置 |
| `user_data_qt/` | QtWebEngine 登录态与缓存（重启免登录） |

源码运行数据目录为项目根目录；打包版为 `%LOCALAPPDATA%\XHSCollector\`。

## 目录结构

```
├── main.py                 # GUI 入口
├── xhs_app/
│   ├── embed.py            # 内嵌浏览器引擎（QtWebEngine + CDP）
│   ├── resolver.py         # 输入解析：小红书号/主页链接（含兜底链）
│   ├── collector.py        # 列表采集（监听 + SSR 兜底）
│   ├── detail.py           # 笔记详情（SSR 解析原图/视频）
│   ├── download.py         # 下载工具（命名/跳过/续传）
│   ├── queue.py            # 下载任务模型 + 本地持久化
│   ├── service.py          # 业务流程 + HTTP 详情通道 + 下载队列引擎
│   ├── ui.py               # 主界面（含任务队列面板）
│   ├── single.py           # 进程单实例守卫
│   ├── models.py / config.py / browser.py
├── test_*.py               # 自动化回归脚本
```
